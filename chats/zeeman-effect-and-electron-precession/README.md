# Chat: Zeeman effect and electron precession

The conversation from which this project grew, 9–11 November 2026.

- [`transcript.md`](transcript.md): the questions and answers.
- [`visuals/`](visuals/): the 13 diagrams and animations from the chat.

## What the chat covers

| Questions | Topic |
|---|---|
| 1–3 | How the Zeeman effect relates to precession; the classical (Lorentz) derivation, step by step |
| 4–12 | Electron spin: the Uhlenbeck–Goudsmit proposal, Stern–Gerlach, the vector model and the Landé g-factor, sodium levels |
| 13–15 | The three sodium levels and the four-line pattern of the D1 line |
| 16–19 | The experiment, the gas-discharge lamp, and how atoms are excited |
| 20–24 | An error in an answer, and the instructions, models and verification rules built in response |
| 25–27 | Putting the project on GitHub |

## Viewing the visuals

GitHub shows HTML files as source code, so the animations do not run on the GitHub page. To see them:

- Download or clone the repository and open a file from `visuals/` in a browser. Keep `style.css` in the same folder.
- Or enable GitHub Pages for the repository (Settings → Pages) and open the files through the Pages address.

The eight static diagrams are also saved as `.svg` files, which GitHub displays directly; the transcript shows them inline.

## Notes on accuracy

- The transcript was copied by hand from the chat; there was no export function. Small differences from the original wording are possible.
- The drawing and animation code is the code used in the chat. The surrounding page and `style.css` were written for this repository to stand in for the styling the chat window supplied, so colours and fonts differ slightly from what was shown there. The standalone `.svg` files use a fixed light colour scheme.
- Animations are cartoons with speeds scaled for visibility, as the transcript says where each appears.
- Several answers in the chat were later corrected (questions 20, 23 and 24 list the corrections). The transcript keeps the answers as given. For the corrected and source-checked content, use [`models/`](../../models/).
